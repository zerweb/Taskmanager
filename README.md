# TaskManager — менеджер задач на Python и SQLite

![Python](https://img.shields.io/badge/Python-3.9%2B-blue)
![SQLite](https://img.shields.io/badge/Database-SQLite-green)

## Описание проекта

**TaskManager** — консольная программа на *Python* для хранения списка дел в базе данных **SQLite**. Задачи сохраняются после закрытия программы в файле `tasks.db`.

> Цель проекта — сделать простой и понятный менеджер задач без дополнительных библиотек.

## Возможности

- Добавление задачи
- Просмотр всех задач
- Отметка задачи как выполненной
- Удаление задачи
- Автоматическое создание базы данных

## Технологии

| Технология | Назначение |
|---|---|
| Python 3.9+ | Основной язык программирования |
| SQLite | Хранение задач |
| `sqlite3` | Встроенный модуль Python для SQLite |
| Markdown | Документация проекта |

## Установка и запуск

1. Установите [Python](https://www.python.org/downloads/).
2. Скачайте файлы проекта или клонируйте свой репозиторий.
3. Откройте папку проекта в терминале.
4. Запустите программу:

   ```bash
   python main.py
   ```

   В некоторых системах команда выглядит так:

   ```bash
   python3 main.py
   ```

Никаких сторонних библиотек устанавливать **не требуется**.

При первом запуске появится файл `tasks.db` — база SQLite.

## Пример использования

При запуске откроется меню:

```text
=== TaskManager (SQLite) ===
1. Добавить задачу
2. Показать задачи
3. Отметить задачу выполненной
4. Удалить задачу
0. Выход
```

1. Введите `1` и название задачи `Подготовить отчет`.
2. Введите `2`, чтобы посмотреть список.
3. Введите `3`, затем ID задачи, чтобы отметить её выполненной.
4. Введите `4`, затем ID задачи, чтобы удалить её.

Пример SQL-запроса, который добавляет новую задачу:

```sql
INSERT INTO tasks (title) VALUES ('Подготовить отчет');
```

## Структура базы данных

Таблица `tasks` создаётся автоматически:

| Поле | Тип | Назначение |
|---|---|---|
| `id` | INTEGER | Уникальный идентификатор |
| `title` | TEXT | Название задачи |
| `is_done` | INTEGER | Статус: 0 — не выполнена, 1 — выполнена |
| `created_at` | TEXT | Дата и время создания |
